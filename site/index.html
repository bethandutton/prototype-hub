Your agent asks why

Ask for a change and the agent asks for the reason first. One line, or skip. The answer is kept as a note on that part of the page, so the decision stays with the design.

Bring your own agent →

Works with the agent you already use

Rehearsal runs a local MCP server that Claude Code, Claude Desktop, Cursor or any other agent can connect to. A skill teaches the agent to load your design library, keep block ids and ask why.

  • Loads your design libraryThe agent starts from your components and tokens, not a blank page.
  • Keeps block idsEdits stay attached to the same element, so its history survives the change.
  • Asks whyBefore it changes anything, it asks for a reason and keeps it.

Every prototype is a plain folder of HTML with its history beside it. On the free plan you share it through Google Drive or any shared folder. Teams adds cloud sync and live collaboration.
