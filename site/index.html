Your agent

Bring your own agent

Rehearsal runs a local MCP server that any agent can connect to. It comes with a skill that teaches the agent how to work here.

Claude CodeClaude DesktopCursorand any agent that speaks MCP

  • Loads your design libraryThe agent starts from your components and tokens, not a blank page.
  • Keeps block idsEdits stay attached to the same element, so its history survives the change.
  • Asks whyBefore it changes anything, it asks for a reason and keeps it.
